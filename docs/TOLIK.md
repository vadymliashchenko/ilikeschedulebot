# Толік — опитування про комфорт (додано 20.10.2026)

ТЗ: `КОНДИЦІОНЕРИ/HA автоматизації/10_TOLIK_TZ.md` (затверджено власником).

## Файли
- `bot/tolik.py` — розклад і розсилка (21:15 ПН–ПТ хореографам і феям, СБ 18:15 феям)
- `bot/handlers/tolik.py` — кнопки (callback «tk:…») і команди
- `bot/tolik_db.py` — нові таблиці `comfort_responses`, `tolik_admins`, `tolik_state` (старі не чіпаються)
- `bot/tolik_texts.py` — усі тексти (можна правити без ризику)
- `docs/tolik_sheet_apps_script.gs` — запис у Google-таблицю

## Змінні Railway
| Змінна | Значення | Що робить |
|---|---|---|
| TOLIK_ENABLED | `false` (за замовч.) / `true` | головний вимикач |
| TOLIK_OWNER_ONLY | `true` (за замовч.) / `false` | `true` — усе приходить лише власнику з позначкою 🧪 |
| TOLIK_SHEET_WEBHOOK | адреса Apps Script + `?key=…` | копія відповідей у Google-таблицю (необов'язково) |
| TOLIK_CHOREO_TIME / TOLIK_ADMIN_TIME / TOLIK_ADMIN_TIME_SAT | `21:15` / `21:15` / `18:15` | час опитувань |
| TOLIK_CHOREO_DAYS | `mon,tue,wed,thu,fri` | дні (через 3 тижні можна зменшити, напр. `mon,thu`) |

## Команди
- Власник: `/toliktest` (приклади лише вам), `/tolikstats` (тиждень), `/tolikintro` (вступ з підтвердженням), `/tolikfei` (список фей)
- Адміністратори: `/feya` → обрати ім'я → власник підтверджує кнопкою

## Запуск
1. Push у main → Railway оновить бота (Толік вимкнений — нічого не зміниться).
2. `/toliktest` у вашому чаті — подивитися, як виглядає.
3. Railway → Variables: `TOLIK_ENABLED=true` (лише вам, 1–2 дні).
4. Після «так» власника: `TOLIK_OWNER_ONLY=false`, потім `/tolikintro`.

Перевірено 20.10.2026 тестовим скриптом (заглушки aiogram; реальна база): хореографи (1–3 заняття, відміни/заміни пропускаються, ✅, зміна відповіді, чужі натискання відхиляються), феї (реєстрація, підтвердження, поверхи, окремо рецепція/роздягалка, термометр, «не працювала»), статистика, тест-режим, вимикач, захист від падіння.
